How the Model Works

  1. Load the flight dataset.
  2. Remove completely empty columns.
  3. Separate the target weather_delay from input features.
  4. Fill missing numeric values using the median.
  5. Fill missing categorical values using the most frequent value.
  6. Convert categorical values into numerical values using One-Hot Encoding.
  7. Scale numerical features.
  8. Split the dataset into 80% training and 20% testing data.
  9. Train the Linear Regression model.
  10. Evaluate the predictions using R², MAE and RMSE.
